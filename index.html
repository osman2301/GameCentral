Installed Steam games

Where are these files?

Click Load…, open C:\Program Files (x86)\Steam\steamapps and select all the appmanifest_….acf files. Another Steam library (e.g. D:\SteamLibrary\steamapps)? Load it too — it adds to the list.

Installed Epic games

Where are these files?

Click Load… and paste C:\ProgramData\Epic\EpicGamesLauncher\Data\Manifests into the address bar (ProgramData is hidden). Game missing? Load the folder your games are installed in instead, e.g. D:\Epic Games.

Installed Battle.net games

Where is this file?

Click Load…, paste C:\ProgramData\Battle.net\Agent into the address bar (ProgramData is hidden) and pick product.db. Not installed yet? Just type the name below — known Battle.net games fill in by themselves.
